## Export details / editing

Icon: 512 × 512 RGB PNG. Thumbnails: 1920 × 1080 sRGB JPEG, quality 96 / 4:4:4.
Every upload file is below 0.71 MB, comfortably under the documented 3 MB guidance.
Keep the provided files at their native dimensions; avoid another lossy recompression.

Editable layouts and original generated masters are in editable/. SVG text is editable
with Impact/Arial fonts; PNG/JPEG masters are flattened artwork. Rebuild exports with
export-assets.cjs using the included Sharp runtime path (adjust that dependency path
on another computer). Lossless PNG counterparts are there for future design work.
